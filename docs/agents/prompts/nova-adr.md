# Prompt · Nova ADR

> Troque `<título>`.

Crie o próximo ADR em `docs/adr/` para a decisão **"<título>"**, usando `docs/adr/_modelo.md`.

- Número: próximo livre (`ADR-NNN-slug.md`).
- Contexto: o requisito do Prompt Mestre envolvido (cite a seção) e a restrição real (custo, equipe solo, Supabase...).
- Pelo menos 2 alternativas reais, com prós, contras e custo mensal estimado.
- Decisão e consequências, incluindo o **risco residual** e o gatilho para reavaliar.
- Se a decisão desvia do Prompt Mestre, diga explicitamente e como o risco é compensado.
- Status `Proposto`; data de hoje. Atualize o índice `docs/adr/README.md`.

Não marque `Aceito`: isso é do Adriano.
